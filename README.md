# Prague Parking 1.0

Inlämningsuppgift 1 i kursen Objektorienterad programmering C# (DSO26, KYH).

Ett konsolprogram för valet parking vid slottet i Prag. Personalen kan
parkera, hämta ut, flytta och söka efter fordon. All data lagras i minnet
och försvinner när programmet stängs.

## Köra programmet

1. Öppna `Inlämningsuppgift Prauge parking v1.slnx` i Visual Studio.
2. Tryck F5.

Kräver .NET 10.

## Funktioner

- Parkera fordon (bil eller MC) och få besked om vilken plats det ska till
- Hämta ut fordon
- Flytta fordon till en annan plats
- Söka efter fordon med registreringsnummer
- Visa hela parkeringen
